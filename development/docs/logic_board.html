a_long(t) = [v(t+0.5 s) − v(t−0.5 s)] / 1 s # same as "speed change in one second" (Tesla, Progressive) yaw(t) = v · tan(δ_wheel / ratio) / (L · (1 + K·v²)) # L = 2.895 m (Grandeur), ratio ≈ 13.5, K ≈ 0.0025 s²/m² a_lat(t) = v · yaw(t) (1-s mean) — cross-checked with d(heading)/dt · v when FusedLocation is available Judgment = ABSTAIN if any required signal is missing / FCA ≤ 3 s before / cruise on / value inside guard band = SUCCESS if value is inside the boundary by more than the guard band = MISS otherwise (internal only; praise_only habits turn MISS into ABSTAIN) guard = 0.02 g (10 Hz) · 0.04 g (1 Hz) · 0.5 s (lead time) · 5 m (lead distance) · +2 km/h (entry speed) Per habit h (after every trip, λ = 0.5^(1/15)): α_h ← α0 + λ(α_h − α0) + successes β_h ← β0 + λ(β_h − β0) + misses α0 = 0.7·4, β0 = 0.3·4 skill_h = α_h / (α_h + β_h) mastered ⇔ BetaInv(0.10; α_h, β_h) ≥ 0.80 and ≥ 5 opportunities Skill Index (0–100) = 100 · Σ w_h · skill_h / Σ w_h over habits with ≥ 5 opportunities w = 3 (tier A: crash-risk evidence) · 2 (tier B: legal duty, intent) · 1 (tier C: anticipation, comfort) · 0 (bonus) re-fit later with fleet outcomes: log E[crashes] = log(km) + Σ β_h · (1 − skill_h) (Poisson GLM, like Tesla's PCF) XP per trip = Σ_successes base_tier(A3 B2 C1 X5) · min(2, ∏ context multipliers: rain 1.5, night 1.25), ≤ 10 per habit per trip + 10 per passed practice; = 0 when the trip had severe speeding, school-zone overspeed, FCA, or ≥ 2 severe events Points = attendance / missions / quiz / mileage tier (plan v0.4 F8), monthly cap 3,000 P — never paid for distance
